# Primera tarea para OpenCode

Abre PowerShell en esta carpeta y ejecuta `opencode --agent intercom`. Pega el siguiente encargo.

> Ejecuta el primer hito de AGENTS.md. Verifica el SDK Android, Java y ADB en el entorno. Crea un proyecto Android mínimo en Kotlin, con minSdk 35, compileSdk 37 y targetSdk 37. Usa AudioManager.setCommunicationDevice. Implementa una pantalla de diagnóstico que enumere las rutas de comunicación, permita seleccionar el casco emparejado, muestre la entrada y salida efectivas y permita grabar una muestra corta y reproducirla a demanda. Añade una comprobación de reproducción de un MP3 o WAV local con el micrófono activo y reporta la ruta usada por cada flujo. Prueba qué ocurre al desconectar el casco y libera recursos al detener la sesión. Compila un APK debug instalable si el SDK está disponible. Si falta algún componente del entorno, deja el código listo hasta donde se pueda verificar e indica el componente y el comando exacto de compilación. Solicita al agente de QA revisar el diagnóstico y deja una prueba de banco breve para ambos pares de teléfonos y cascos. Entrega la ruta del APK si se generó y la evidencia disponible. La prueba entre teléfonos corresponde al siguiente hito.
